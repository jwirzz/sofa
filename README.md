## Install

No Deno or Node required:

```sh
curl -fsSL https://raw.githubusercontent.com/jwirzz/sofa/main/install.sh | sh
```

Installs to `~/.sofa/bin` (override with `SOFA_INSTALL`); pin a version with `SOFA_VERSION=v0.1.0`.
